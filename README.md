\# Online Quiz Application



\## Project Overview



The \*\*Online Quiz Application\*\* is a console-based application developed using Java. It allows a participant to answer multiple-choice questions, checks the submitted answers, and displays the final quiz score and performance.



\## Features



\- Accepts the participant's name.

\- Displays multiple-choice questions with four options.

\- Accepts answers in A, B, C, or D format.

\- Validates user input and asks again when an invalid option is entered.

\- Calculates correct and incorrect answers.

\- Displays the score and percentage.

\- Shows a performance message based on the percentage.

\- Allows the participant to play the quiz again.



\## Technologies Used

\- Classes and objects

\## How to Run the Project



1\. Download or clone this repository.

2\. Open PowerShell or a terminal in the project folder.

3\. Compile the Java files:



```bash

javac Main.java Question.java

```



4\. Run the application:



```bash

java Main

```
